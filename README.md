# st

Personal build with:

- transparent background
- HarfBuzz text shaping and ligatures
- correctly shaped color emoji, including skin tones and ZWJ sequences
- personal font, colors, opacity, and keybindings
- touchpad scrollback; edge-drag or Shift-click to extend selections

Requires Xlib, Xft, Fontconfig, FreeType, HarfBuzz, and Noto Color Emoji.

```sh
make
sudo make install
```
